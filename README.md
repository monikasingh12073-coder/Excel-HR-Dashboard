# HR Analytics Dashboard – Excel

## Project Overview
This project presents an interactive HR Analytics Dashboard created using Microsoft Excel.

## Key Insights
- Total Employees
- Active Employees
- Employee Attrition
- Attrition Rate
- Average Employee Age
- Attrition by Department, Job Role, Education and Age Group

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis

## Project Objective
To analyse employee data and understand workforce trends and attrition patterns.
